# luna-dev

Frontend workspace for Luna agent runs.

## Stack

- React + TypeScript
- Vite

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — Vite dev server
- `npm run build` — typecheck + production build
- `npm run preview` — preview production build
- `npm run lint` — ESLint
- `npm run typecheck` — `tsc --noEmit`
