# Agentwise

Frontend for the Agentwise real estate marketing platform.

## Stack

- React + TypeScript
- Vite
- styled-components
- react-router-dom
- axios

## Getting started

```bash
npm install
cp .env.example .env
npm run dev
```

## Scripts

- `npm run dev` — start Vite dev server
- `npm run build` — typecheck and production build
- `npm run lint` — ESLint
- `npm run format` — Prettier
